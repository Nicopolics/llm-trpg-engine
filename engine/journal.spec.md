# JOURNAL 仕様 — 進行メモ

`JOURNAL.md` は、キャンペーンの進行を**文章で追記していく記録**。開発でいう Plan.md に当たる。
セッションをまたいでも「どこまで遊んだか」を、LLMの記憶ではなく紙の上から再開できるようにする。

---

## なぜ要るか

既存の記録は、どれも物語の経緯を持たない。

| 記録 | 残るもの | 残らないもの |
|------|---------|-------------|
| `CHANGELOG.md` | 開示操作・状態操作・ゲートの印（型付き動詞） | 何がどう起きたかの流れ |
| `saves/` と `state.yaml` | 台帳の値と開示度 | 経緯、追っている話 |
| `world/04_events.md` ほか | 世界の真実（GM専用） | プレイヤーが体験したこと |

「あの場面の続きから」を会話履歴に頼ると、コンテキストの希釈で忘れる。
だから経緯も、指示ではなく機構（ファイル）に置く。

---

## 構成

```
# JOURNAL

## 現在地
- 直近の場面: ...
- 進行中の糸口: ...
- 私(player)が次にやろうとしていること: ...

## 経緯
### SAVE 1 / autumn.d01.dawn
- ...
### SAVE 2 / autumn.d02.night
- ...
```

### 現在地（上書き）

セーブのたびに最新へ書き換える。3項目だけ。

| 項目 | 書くこと |
|------|---------|
| 直近の場面 | いま何が起きているか。1〜2行 |
| 進行中の糸口 | プレイヤーが追っている話・受けた依頼・交わした約束・未回収のもの |
| 私(player)が次にやろうとしていること | プレイヤーが**言動で示した**意図だけ。GMが推測して書かない（player主権） |

### 経緯（追記のみ）

セーブごとに `### SAVE <通し番号> / <ゲーム内時刻>` の見出しを足し、起きたことを箇条書きで書く。

- 通し番号は開示スナップショット（`SAVE <n>`）・`meta.save_seq` と揃える。
- 要約や解釈ではなく、**その場で起きたこと**を順に書く。プレイヤーが見たもの・聞いたもの・選んだこと。
- 長くなるなら箇条書きを増やす。盛らない。解釈を足さない。

---

## 規則

1. **経緯は追記のみ。現在地だけ上書き。** 過去の行は書き換えない。誤りは新しい行で訂正する
   （`CHANGELOG.md` と同じ）。
2. **書くのはプレイヤーに表出したことだけ。** チャネルを通って届いたもの（NPCの発話・文書・観察）に限る。
   伏せた真実（Canon）は書かない。GM専用の計画は `world/`（例: `04_events.md`）に置く。
   - 偽情報は、プレイヤーが聞いた内容としてなら書ける
     （「二重間諜は、水先案内人を中立の技術者だと言った」）。嘘だと断定する書き方はしない。
     `CORRECT` が起きるまでは、プレイヤーにとって事実として届いている。
3. **台帳と facts の値を書き写さない。** 所持金・在庫・HP・位置・時刻・クエストの段階・開示度。
   場面の叙述として自然に触れるのは構わない。食い違えば台帳と facts が勝つ。
4. **JOURNAL から状態を復元しない。** `state.yaml` や `facts/` を JOURNAL から作り直すのは禁止
   （「会話履歴から復元」の禁止と同じ）。JOURNAL は正本ではない。
5. **再開時に渡すのは、現在地と直近の経緯だけ。** 目安は直近3セーブ分。全文を渡すと文脈が薄まる。
   全文は人間用のアーカイブとして残す。

---

## いつ・誰が書くか

保存の一部として、GMが書く。

- **セーブ時のみ。** 監査が PASS のときだけ追記する。FAIL で保存が無効になったときは、
  JOURNAL も書かない（`AUDIT_PROTOCOL.md` の STEP 4）。
- **コード無し版:** STEP 5 で、スナップショット・台帳と並べて、更新後の「現在地」と今回の「経緯」を出力する。
  人間はそれを `JOURNAL.md` に反映して保管し、次回冒頭に現在地と直近の経緯を貼る。
- **ファイルを書ける環境:** GMが `campaigns/<name>/JOURNAL.md` に直接追記する。

## ゲートとの関係

Python版ゲート（`tools/export_gate.py`）も、コード無し版の監査も、JOURNAL は検査しない。
規則は GM契約の第8条で縛る。

検査の拡充の候補: 伏せた真実（`hidden` な fact の canon）の混入、通し番号とスナップショットの不一致。
